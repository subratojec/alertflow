Why AlertFlow?

Alert routing is deceptively hard

A single misplaced indent, an overlooked continue: true, or an unexpected inhibition rule can silently drop mission-critical alerts.

The Traditional Way
  • Reading massive, 500+ line alertmanager.yml files by hand.
  • Linters only check YAML syntax, completely blind to routing logic.
  • Inhibition suppression cannot be verified until an actual incident happens.
  • Pull requests break team notifications without anyone noticing in review.
The AlertFlow Way
  • Instant visual graph of your entire route tree, receivers, and timings.
  • Simulates the real Prometheus Go dispatch engine in your browser.
  • Multi-alert batch testing shows active suppression and muted intervals.
  • CI/CD CLI diff tool fails pull requests if routing behavior regresses.
Core Capabilities

Everything you need to master alert routing

Simulation Engine

See alert dispatching live before production

Alertmanager's inhibition rules suppress lower-severity alerts when high-severity alerts fire with matching tags. AlertFlow runs this exact algorithm live in your browser.

  • Vibrant Green Path: Highlights matched routes & terminal receiver endpoints.
  • Inhibition Badges: Suppressed alerts turn red with explanation of which alert caused it.
  • Mute Highlights: Routes caught in maintenance intervals turn orange.

Automated Testing

Catch routing regressions before they merge

AlertFlow isn't just a UI tool. It ships with a fast Go CLI designed to run in GitHub Actions to ensure pull requests don't silently route alerts to the wrong receiver.

Terminal — CI Pipeline bash 
# 1. Validate syntax and detect orphan receivers
alertflow check alertmanager.yml

# 2. Diff routing behavior against test alerts
alertflow diff old.yml new.yml --alerts sample-alerts.json

# 3. Export Mermaid diagram for PR comment bots
alertflow mermaid alertmanager.yml --markdown
